### What I've shipped

> **Order processing automation pipeline**
> Raw email → LLM classification → PO data extraction → Supabase price validation → CSV generation → ERP file drop. Zero manual intervention on clean orders. HITL escalation via Zendesk for low-confidence cases. ~14 orders/day processed automatically.

> **Multi-agent orchestration system**
> Master Router → sector-specific sub-workflows with a shared Supabase leads pool, two-LLM-call scraper loop, confidence scoring, and intelligent client matching. Live in production.

> **Membership intake pipeline**
> End-to-end applicant flow: intake form → weighted scoring rubric (100pt scale, 2 sections) → Airtable write → CRM stage push → automated email dispatch. Rebuilt from scratch, resolved 5 critical production bugs.

> **Canadian data residency migration**
> Supabase cross-region migration to `ca-central-1` for compliance deadline — schema transfer, RLS policy audit, credential cutover strategy, zero downtime.

> **Shared staging infrastructure**
> OCI AMD instance, Ubuntu 22.04, Docker Compose stack, Cloudflare Tunnel, Terraform. Reproducible from scratch.

> **Production web platform — Azmam**
> [Live ↗](https://azmam.netlify.app/home) · 50+ active users · 6 months in production · Magic Link + Google OAuth · offline-first · weekly releases · ~30% load performance improvement

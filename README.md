## What I build

**End-to-end ERP automation pipelines**
Production order processing systems connecting email ingestion → LLM extraction → Supabase validation → Epicor ERP, replacing manual data entry for enterprise manufacturing clients.

Multi-agent n8n systems with HITL review layers, confidence scoring, and automatic escalation — live across multiple client accounts.
